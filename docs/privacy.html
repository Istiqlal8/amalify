Kebijakan Privasi

Berlaku sejak 26 September 2026.

Amalify dirancang agar catatan ibadahmu tetap milikmu. Halaman ini menjelaskan data apa yang dipakai aplikasi, di mana disimpan, dan siapa yang bisa melihatnya.

Data yang tersimpan di perangkat dan Google Drive-mu

Checklist amal yaumi, riwayat harian, daftar amalan, catatan tilawah, serta catatan haid (tanggal, gejala, dan pengingat) disimpan di perangkatmu. Jika kamu masuk dengan Google, data ini disinkronkan ke folder aplikasi tersembunyi (appDataFolder) di Google Drive milikmu. Folder itu hanya bisa diakses oleh Amalify dan memakai kuota Drive-mu sendiri. Kami tidak bisa membaca isinya.

Amalify hanya meminta izin drive.appdata. Aplikasi tidak bisa melihat file lain di Google Drive-mu.

Data yang dikirim ke server kami

Hanya jika kamu masuk dengan Google, data berikut disimpan di server Supabase untuk fitur grup dan leaderboard:

DataSiapa yang bisa melihat
Nama tampilan dan ID akunAnggota grupmu; nama juga tampil di leaderboard tilawah global
Persentase amal yaumi harianAnggota grupmu
Jumlah halaman tilawah harianAnggota grupmu dan leaderboard global
Grup, event, dan catatan kas yang kamu buatAnggota grup tersebut

Rincian amalan yang kamu kerjakan dan data haid tidak pernah dikirim ke server kami.

Layanan pihak ketiga

  • Google Sign-In dan Google Drive: login dan penyimpanan cadangan.
  • Supabase: penyimpanan data grup di atas.
  • api.myquran.com: jadwal sholat berdasarkan kota yang kamu pilih.
  • api.aladhan.com: arah kiblat. Koordinat lokasimu dikirim hanya saat membuka fitur Kiblat dan tidak disimpan oleh Amalify.
  • equran.id: teks Al-Qur'an.

Izin perangkat

  • Lokasi: untuk arah kiblat, hanya saat fitur itu dibuka.
  • Notifikasi dan alarm tepat waktu: untuk adzan dan pengingat amalan.

Menghapus data

Keluar dari akun di menu Pengaturan menghentikan sinkronisasi. Kamu bisa menghapus data Amalify di Google Drive lewat Drive → Setelan → Kelola aplikasi → Amalify → Hapus data aplikasi tersembunyi. Untuk menghapus akun dan data grup di server kami, kirim email ke alamat di bawah dan kami hapus dalam 30 hari.
